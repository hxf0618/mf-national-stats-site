Japan by Numbers — an independent statistics portal for Japan: population, economy, employment, prices, education, health and the regions, each figure with its year and source. A static site with no build step and no network requests; charts are hand-drawn inline SVG and every control (year picker, indicator switcher, prefecture comparison) works.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
